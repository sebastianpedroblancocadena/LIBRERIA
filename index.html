Sección Técnica para Jurados y Evaluadores

Arquitectura, Seguridad & Viabilidad del Proyecto

Explicación de la infraestructura informática, bases de datos 24/7, cifrado de alta seguridad, sincronización en tiempo real con Webhooks y estudio financiero de rentabilidad.

Base de Datos Ininterrumpida 24/7

Toda la información (catálogo de productos, usuarios, compras y stock online) se almacena en un clúster de base de datos relacional (MySQL / PostgreSQL) alojado en la nube con réplicas activas y balanceador de carga.

  • Disponibilidad 99.9% ininterrumpida
  • Transacciones ACID (Evita sobreventas)
  • Copias de seguridad automáticas diarias

Seguridad SSL & Cifrado 🔒

El sistema opera bajo conexión cifrada mediante certificados SSL/TLS con encriptación de 256 bits, garantizando la privacidad absoluta de los datos de padres de familia y las transacciones de pago.

  • Certificado TLS 1.3 End-to-End
  • Protección contra ataques CSRF y SQL Injection
  • Cumplimiento estricto de privacidad escolar

Sincronización con Webhooks

Utiliza eventos asíncronos (Webhooks) para sincronizar en tiempo real el servidor backend en Python, la base de datos y la interfaz de usuario con la API de Meta Cloud (WhatsApp).

  • Descuento de stock en milisegundos
  • Disparo automático de WhatsApp oficial
  • Arquitectura desacoplada y escalable
